Uso

Clic en un elemento para añadirlo. Arrastra para mover. Arrastra desde el punto azul de un nodo hasta otro para crear un flujo. Supr elimina la selección. Rueda = zoom, arrastrar el fondo = desplazar.

Ejemplos (.bpmn)

Todos pasan por el importador BPMN 2.0; también puedes descargarlos con «Exportar .bpmn».

Semántica

Símbolos: cada actividad (task y subtipos) emite exactamente un símbolo al completarse; Σ = símbolos de las tareas. Inicio, fin, compuertas y flujos de secuencia son ε (no emiten símbolo).
Estados: q0 = tras el inicio; un estado por tarea (tras ejecutarla); qError como sumidero. δ(q, s) = estado de la tarea con símbolo s alcanzable desde q atravesando solo XOR.
Aceptación: una cadena se acepta si lleva de q0 a un estado desde el que se alcanza un fin solo por XOR. Las condiciones no forman parte del AFD: solo las usa la ejecución con datos.

Subconjunto BPMN soportado

startEvent, endEvent, task y subtipos, exclusiveGateway, sequenceFlow con condición simple (${var == valor}, true/false) o default. Lo demás (AND/OR, subprocesos, eventos intermedios, pools…) se importa marcado como no soportado y bloquea el análisis; no se simula.
